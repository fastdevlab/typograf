# Плагин «Типографика» для TinyMCE 6

Адаптация плагина [Dominus77/typograf](https://github.com/Dominus77/typograf/tree/tinymce5) для TinyMCE 6.

Плагин использует библиотеку [Typograf](https://github.com/typograf/typograf), которая помогает расставлять неразрывные пробелы, исправлять отдельные типографические ошибки, оформлять кавычки, заменять дефисы на тире в подходящих местах и применять другие правила.

Обработка запускается кнопкой в редакторе. Результат можно отменить через Undo.

## Статус

Код адаптирован под API TinyMCE 6 и прошел проверку синтаксиса JavaScript.

Прощел проверку в браузере и MODX 3.2.4.

Совместимость с другими основными версиями TinyMCE отдельно не подтверждена.

## Что изменено

По сравнению с исходным плагином для TinyMCE 5:

- настройки читаются через `editor.options`;
- опция `typograf` регистрируется через `editor.options.register`;
- загрузка библиотеки использует Promise API;
- обработка привязана к переданному экземпляру редактора, а не к глобальному `activeEditor`;
- добавлены сообщения об ошибках загрузки и обработки;
- изменение содержимого выполняется через Undo-транзакцию;
- после обработки отправляется событие изменения.

## Состав файлов

Сохраняйте структуру каталога:

```text
typograf/
├── plugin.min.js
├── dist/
│   ├── typograf.all.min.js
│   └── typograf.css
└── langs/
```

`plugin.min.js` содержит адаптацию для TinyMCE 6.

Папки `dist` и `langs` используются из исходного проекта. Не удаляйте другие файлы, находящиеся внутри них.

Файл `typograf.css` нужен при использовании оптического выравнивания.

## Установка через external_plugins

1. Скачайте или склонируйте проект.
2. Разместите каталог `typograf` в доступной через HTTP папке сайта.
3. Укажите публичный адрес `plugin.js` в `external_plugins`.
4. Добавьте кнопку `typograf` в панель инструментов.

Например, файлы размещены здесь:

```text
/assets/editor/tinymce/plugins/typograf/
```

Пример настройки уже подключенного TinyMCE:

```js
tinymce.init({
    selector: 'textarea',

    external_plugins: {
        typograf: '/assets/editor/tinymce/plugins/typograf/plugin.min.js'
    },

    toolbar: 'undo redo | bold italic | typograf'
});
```

Если редактор уже настроен, добавьте эти параметры в существующую конфигурацию. Не создавайте второй `tinymce.init()` для того же поля и не заменяйте весь список кнопок приведенным примером.

Плагин, объявленный через `external_plugins`, не требуется дополнительно дублировать в `plugins`.

Если сайт установлен в подпапке, учитывайте ее в адресе:

```js
external_plugins: {
    typograf: '/site/assets/editor/tinymce/plugins/typograf/plugin.min.js'
}
```

## Установка в MODX

Для TinyMCE Rich Text Editor используйте внешний JSON-конфиг компонента.

Добавьте в существующий объект:

```json
{
    "external_plugins": {
        "typograf": "/assets/editor/tinymce/plugins/typograf/plugin.js"
    }
}
```

Если `external_plugins` уже содержит другие плагины, добавьте `typograf` внутрь существующего объекта.

Затем:

1. Добавьте кнопку `typograf` в `tinymcerte.toolbar1` или другую используемую строку панели.
2. Если старый `typograf` остался в `tinymcerte.plugins`, уберите его оттуда, чтобы не загружать прежний файл из каталога встроенных плагинов.
3. Сохраните настройки.
4. Заново откройте форму ресурса.
5. При необходимости выполните жесткое обновление страницы браузера.

Не заменяйте пользовательские файлы внутри поставляемого ядра TinyMCE, если плагин можно подключить через `external_plugins`.

## Настройка типографики

Без дополнительных параметров используются локали `ru` и `en-US`.

Пример JavaScript-конфигурации:

```js
tinymce.init({
    selector: 'textarea',

    external_plugins: {
        typograf: '/assets/editor/tinymce/plugins/typograf/plugin.js'
    },

    toolbar: 'undo redo | bold italic | typograf',

    typograf: {
        locale: ['ru', 'en-US'],

        htmlEntity: {
            type: 'name',
            onlyInvisible: true
        },

        enableRule: [
            // 'ru/money/ruble',
            // 'ru/money/*',
            // 'ru/symbols/NN',
            // 'ru/optalign/*'
        ],

        disableRule: [
            // 'ru/money/ruble',
            // 'ru/money/*',
            // 'ru/symbols/NN'
        ],

        setSetting: [
            // Неразрывный пробел перед последним коротким словом.
            ['common/nbsp/beforeShortLastWord', 'lengthLastWord', 5],

            // Настройка русских кавычек.
            [
                'common/punctuation/quote',
                'ru',
                {
                    left: '«',
                    right: '»',
                    removeDuplicateQuotes: true
                }
            ],

            // Неразрывный пробел после короткого слова.
            ['common/nbsp/afterShortWord', 'lengthShortWord', 5]
        ],

        addSafeTag: [
            ['<no-typography>', '</no-typography>'],
            ['\\{\\{', '\\}\\}'],
            ['\\[\\[', '\\]\\]'],
            ['<\\?php', '\\?>']
        ]
    }
});
```

Используйте только нужные изменения правил. Имена правил и доступные параметры зависят от версии библиотеки Typograf в папке `dist`.

Описание правил и API находится в [репозитории Typograf](https://github.com/typograf/typograf).

## Настройка через JSON в MODX

В JSON нельзя использовать комментарии, функции и завершающие запятые.

Пример:

```json
{
    "external_plugins": {
        "typograf": "/assets/editor/tinymce/plugins/typograf/plugin.min.js"
    },
    "typograf": {
        "locale": ["ru", "en-US"],
        "htmlEntity": {
            "type": "name",
            "onlyInvisible": true
        },
        "disableRule": [
            "ru/money/ruble"
        ],
        "addSafeTag": [
            ["\\{\\{", "\\}\\}"],
            ["\\[\\[", "\\]\\]"],
            ["<\\?php", "\\?>"]
        ]
    }
}
```

Добавляйте эти параметры в действующий конфиг, сохраняя остальные настройки редактора.

## Добавление собственного правила

Собственное правило с функцией можно передать в JavaScript-конфигурации:

```js
typograf: {
    addRule: [
        {
            name: 'common/other/typographicSmiley',
            handler: function (text) {
                return text.replace(/:-\)/g, ':—)');
            }
        }
    ]
}
```

Это пример расширения библиотеки, а не обязательная настройка.

Такую функцию нельзя скопировать в обычный JSON. Для проекта с JSON-конфигурацией потребуется отдельное JavaScript-подключение или изменение конфигурации плагина доверенным разработчиком.

## Оптическое выравнивание

Для включения соответствующей группы правил:

```js
typograf: {
    enableRule: [
        'ru/optalign/*'
    ]
}
```

Адаптер подключает `dist/typograf.css` к документу редактора при включении этой группы.

Для отображения результата на публичной странице потребуется соответствующий CSS и на сайте. Подключение стилей внутри редактора не добавляет их автоматически в шаблон страницы.

Перед использованием проверьте, как созданная разметка сохраняется TinyMCE и выводится вашим шаблоном.

## Безопасные участки текста

`addSafeTag` позволяет исключать определенные участки из обработки Typograf.

Это не механизм защиты от выполнения кода и не гарантия сохранности шаблонных конструкций самим TinyMCE.

Если MODX, Fenom или другой обработчик выполняет конструкции после сохранения, настройка Typograf не отключает это поведение.

Для показа примеров кода используйте подходящую разметку и отдельно проверяйте результат.

## Проверка после установки

1. Откройте тестовое содержимое в TinyMCE.
2. Убедитесь, что нет ошибки инициализации `typograf`.
3. Проверьте загрузку `plugin.js`, файлов `dist` и языковых файлов во вкладке Network браузера.
4. Вставьте короткий текст с кавычками, пробелами и дефисами.
5. Нажмите кнопку «Типограф».
6. Проверьте результат.
7. Отмените изменение через Undo.
8. Повторите обработку, сохраните содержимое и откройте его заново.
9. Если на странице несколько редакторов, проверьте каждый экземпляр отдельно.

В MODX дополнительно проверьте работу в основном содержимом и в TV, если используете редактор в обоих местах.

## Диагностика

### Ошибка инициализации плагина

Проверьте, что загружается адаптированный `plugin.min.js`, а не старая копия.

Посмотрите фактический URL в Network и сообщение в консоли браузера.

### Не загрузилась библиотека Typograf

Проверьте наличие:

```text
typograf/dist/typograf.all.min.js
```

Каталог `dist` должен находиться рядом с новым `plugin.min.js`.

### Кнопка есть, но обработка недоступна

Возможно, библиотека еще загружается или при загрузке произошла ошибка. Проверьте уведомление редактора, консоль и сетевые запросы.

### Не работают отдельные правила

Сверьте имена правил с версией Typograf, которая фактически используется в проекте.

Не заменяйте библиотеку в `dist` другой основной версией без проверки API и результата обработки.
